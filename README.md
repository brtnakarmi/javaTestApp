# Java Practice Web App

This is a dependency-free Java web app using Java's built-in HttpServer.

## Run

```bash
cd java-webapp
javac -d out src/main/java/com/example/PracticeApp.java
java -cp out com.example.PracticeApp
```

Open: http://localhost:8080
